# THE INVISIBLE
### The architecture of thought.

**An interactive exploration of the extraordinary biology behind human thought.**

The Invisible is an experimental web experience at the intersection of neuroscience, creative coding, and interactive design.

At its center is a three-dimensional neuron, suspended in a vast, atmospheric universe. Through scientifically inspired geometry, cinematic lighting, and subtle interaction, the project transforms microscopic biology into an immersive digital experience.

The concept is simple: **make the invisible visible.**

---

## The Concept

The human brain contains billions of neurons, each forming part of an extraordinarily complex communication network.

Yet the structures responsible for our thoughts, memories, and experiences remain largely invisible to us.

The Invisible explores how modern web technologies can reveal these hidden biological structures through interactive visualization.

Rather than presenting neuroscience as a collection of static diagrams, the project approaches scientific communication as an experience — one that invites curiosity, exploration, and discovery.

## Design Philosophy

**Scientific integrity. Artistic expression.**

The visual language draws inspiration from biological microscopy, fine art, and the vastness of the cosmos.

The neuron is represented as a delicate organic sculpture, surrounded by darkness, distant stars, and carefully controlled light.

The experience follows four principles:

- **Biological credibility** — morphology inspired by real neuronal structures.
- **Visual restraint** — minimal typography, subtle motion, and intentional use of light.
- **Meaningful interaction** — exploration that supports scientific understanding.
- **Technical precision** — maintainable architecture, performance-conscious rendering, and accessible interfaces.

The cosmic environment is an artistic metaphor connecting the microscopic and the infinite, rather than a literal representation of neuronal biology.

## Technology

Built with modern frontend technologies:

- **React** — component-based application architecture.
- **TypeScript** — type-safe development.
- **Three.js** — real-time 3D graphics.
- **React Three Fiber** — declarative 3D rendering within React.
- **Drei** — utilities for 3D interaction and scene composition.
- **Vite** — development tooling and production builds.

The neuronal morphology is generated procedurally, allowing its structure and appearance to be controlled through code.

## Current Development

The project is under active development.

The initial experience focuses on the visual representation of a neuron, including:

- Procedural neuronal geometry.
- Interactive 3D exploration.
- Cinematic biological materials and lighting.
- A layered cosmic environment.
- Responsive composition and motion accessibility.

## Future Exploration

Planned directions include:

- Interactive action potential propagation.
- Synaptic transmission visualization.
- Exploration of dendrites, axons, and neuronal structures.
- Biologically informed signal simulations.
- Educational interactions connecting visual events to their underlying mechanisms.

These features will be developed incrementally, with a distinction between scientifically modeled processes and artistic interpretation.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MijaMange/theinvisible.git
cd theinvisible
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite.

To create a production build:

```bash
npm run build
```
